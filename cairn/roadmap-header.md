## Road to 1.0

tsi is a library before it is a CLI. It gets the physics right, shows its work
and uses real hardware. The four milestones to 1.0 follow a launch campaign,
and each one has to pass before the next begins:

| Milestone | Name | What it proves |
|-----------|------|----------------|
| v0.7 | **Static fire** | Numbers are right, the build is green, and CI enforces both |
| v0.8 | **Stacking** | The library can be depended on without pulling in a CLI |
| v0.9 | **Wet dress** | tsi explains itself, knows real vehicles and speaks in missions |
| v1.0 | **Liftoff** | The API is frozen, and one `cargo install` works everywhere |
